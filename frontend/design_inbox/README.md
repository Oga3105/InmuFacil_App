# Design Inbox

Esta carpeta contiene archivos temporales exportados de Google Stitch para ser procesados por @UIBuilder.

## Formato Esperado

Cada diseño debe incluir:
- `[screen_name].html` - Estructura HTML
- `[screen_name].png` - Captura visual

## Proceso

1. Exportar diseño de Stitch a esta carpeta
2. @UIBuilder procesa y convierte a Flutter widgets
3. Una vez procesado, eliminar archivos de aquí

## Nota

Esta carpeta está en `.gitignore` - los archivos NO se suben al repositorio.
